# RAR5 口令恢复工具

[![Python](https://img.shields.io/badge/Python-3.9%2B-blue)](https://www.python.org/)
[![License](https://img.shields.io/badge/License-MIT-green)](LICENSE)

用于**找回你自己文件**的 RAR5（WinRAR 5.x / 6.x / 7.x）加密压缩包口令的离线校验与尝试工具。
全程**只读**：不修改、不解压、不破坏原文件，仅在内存中验证候选口令是否正确。

> ⚠️ **免责声明**：本工具仅用于恢复你本人创建或合法拥有的文件的解压口令。
> 请勿用于未经授权访问他人数据。使用者需自行承担合规责任。

---

## 特性

- **图形界面 + 命令行**双形态，图形界面基于 Python 内置 tkinter，无需额外安装
- 支持 **RAR5 头部全加密（WinRAR 的 `-hp` 模式）**：直接读取加密头中的 Salt 与 8 字节口令校验值做离线比对，**无需解密整个压缩包**，因此 200MB 的包也能秒级开始尝试
- **自动选择最快后端**：`cryptography`(OpenSSL) → `hashlib` 自动回退，前者约快 2 倍
- **多进程并行**，可随时暂停 / 继续 / 停止
- **断点续跑**：进度自动落盘，关掉程序下次可从中断处继续
- **字典攻击**：支持变形规则（首字母大写、全部大写、尾部追加 `0-9` / `00-99` / `123`·`888`·`520`·`!`），并在 GBK 字典下自动按 UTF-8 再试一遍
- **暴力枚举**：自由选择**密码位数区间**与**字符类型**（数字 / 小写 / 大写 / 符号 / 自定义字符），支持固定前缀后缀
- **内置弱口令快检**：几十条最常见的弱口令，几秒跑完
- 算法与 UnRAR / hashcat 完全一致，并内置 **hashcat 官方测试向量自检**

## 原理

RAR5 的加密头（`HEAD_CRYPT`）本身就是明文的，它保存了口令校验所需的一切：

| 字段 | 长度 | 说明 |
|---|---|---|
| Encryption version | 1 | 恒为 0（AES-256） |
| Flags | 1 | `0x01` 表示存在口令校验值 |
| KDF count (Lg2) | 1 | 迭代次数 = `2^Lg2`，WinRAR 默认 `Lg2=15` → 32768 次 |
| Salt | 16 | 密钥派生用盐 |
| pswcheck | 8 | 口令校验值 |
| pswcheck csum | 4 | `sha256(pswcheck)[:4]`，用于校验头部完整性 |

口令校验算法（与 UnRAR / hashcat 一致）：

```
dk       = PBKDF2-HMAC-SHA256( password_utf8 , salt , 2^Lg2 + 32 , 32 字节 )
pswcheck = dk[0..7] ^ dk[8..15] ^ dk[16..23] ^ dk[24..31]     # 按字节折叠
```

`pswcheck` 与压缩包加密头中的 8 字节值相同 ⇒ 口令正确。整个验证过程**不需要 AES 解密**，所以速度快且不依赖 unrar/WinRAR。

> 注：RAR5 的加密头中**不含 IV**（IV 只存在于"文件级加密记录"里），因此离线校验只需要 Salt + Lg2 + pswcheck 三样东西。

## 快速开始

### 1) 图形界面（推荐）

```bash
python rar5_crack_ui.py
```

操作流程：

1. 点「选择文件…」选中加密包 → 自动解析并显示 Salt、迭代次数、头部完整性
2. 选一个页签配置搜索范围：
   - **字典攻击**：选择字典文件 + 勾选变形规则
   - **暴力枚举**：勾选字符类型、设定密码位数区间（含常用预设下拉：6 位纯数字 / 1-6 位小写+数字 / 1-6 位全字符 等）
   - **内置弱口令**：一键快检
3. 「并行进程数」保持默认（自动取 CPU 线程数，上限 24）
4. 点 **▶ 开始**，界面实时显示已试个数、速度、已用时间、进度与**预计剩余时间**
5. 找到口令后自动弹窗、写入文件，并可一键复制

补充说明：

- **暂停 / 停止后进度会保存**到 `rar5_progress.json`，下次「开始」会询问是否从断点继续
- 命中结果写入 `<压缩包同名>.password.txt`
- 提示：暴力枚举前请看清界面给出的「候选总数 ≈ ? 个 / 预估耗时 ≈ ?」，避免开出需要几个月才能跑完的任务

### 2) 命令行

```bash
python rar5_recover.py --selftest                          # 算法自检 + 本机测速

python rar5_recover.py "文件.rar" --info                    # 只看加密头信息
python rar5_recover.py "文件.rar" --builtin                 # 内置常见弱口令快检
python rar5_recover.py "文件.rar" -w 字典.txt               # 字典攻击
python rar5_recover.py "文件.rar" --mask "?d?d?d?d?d?d"     # 6 位纯数字
python rar5_recover.py "文件.rar" -w 字典.txt -j 8          # 指定 8 个进程
```

| 参数 | 说明 |
|---|---|
| `archive` | RAR5 加密包路径（按**文件签名**识别，扩展名是 `.txt`、`.jpg` 等伪装也无所谓） |
| `-w, --wordlist` | 字典文件，每行一个候选口令 |
| `--builtin` | 使用内置常见弱口令 |
| `--mask` | 掩码爆破，支持 `?d` 数字、`?l` 小写、`?u` 大写、`?s` 符号、`?a` 小写+数字、`?A` 大小写+数字，其余字符按字面量 |
| `--info` | 只输出加密头信息后退出 |
| `--selftest` | 用 hashcat 官方向量验证算法并测速 |
| `-j, --workers` | 并行进程数，默认取 CPU 线程数 |

## 性能参考

以下为本项目在 `Intel Core i7-14650HX（24 线程）` 上的**实测**数据（单候选需完整跑 32800 次 PBKDF2-HMAC-SHA256）：

| 后端 | 单核 | 24 线程并行 |
|---|---|---|
| `hashlib`（标准库） | ≈ 11.5 ms / 个 | ≈ 2,100 个/秒 |
| `cryptography`（OpenSSL） | ≈ 4.6 ms / 个 | ≈ 5,200 个/秒 |

不同搜索空间的耗时对照（按 5,200 个/秒估算）：

| 搜索空间 | 候选总数 | 预计耗时 |
|---|---|---|
| 6 位纯数字 | 1.0 × 10⁶ | ≈ 3.2 分钟 |
| 1-6 位纯数字 | 1.1 × 10⁶ | ≈ 3.6 分钟 |
| 4 位小写字母 | 4.6 × 10⁵ | ≈ 1.5 分钟 |
| 8 位纯数字 | 1.0 × 10⁸ | ≈ 5.3 小时 |
| 6 位小写字母 | 3.1 × 10⁸ | ≈ 16.5 小时 |
| 6 位小写+数字 | 2.2 × 10⁹ | ≈ 4.8 天 |
| 6 位全字符（95 种） | 7.4 × 10¹¹ | 不可行 |

> **重要**：RAR5 使用高迭代的 PBKDF2-HMAC-SHA256，属于"慢哈希"。
> 不存在"破解"捷径（没有后门、没有万能密码、无已知密码学弱点），**唯一的办法就是猜口令**。
> 口令一旦足够长且随机（比如 10 位以上混合字符），在个人设备上基本不可能恢复——此时正确的做法是向压缩包来源索取解压密码。

## 常见问题

**Q：能破解 ZIP / RAR4 / 7z 吗？**
A：不能。本工具只处理 RAR5 的 `HEAD_CRYPT` 结构。若提示"第一个头不是加密头"，说明该包加密方式不同（例如只加密了文件内容而未加密文件名），需要配合 WinRAR / 7-Zip 使用。

**Q：为什么校验要 32800 次而不是 32768 次？**
A：WinRAR 在派生主密钥（32768 次）之后，还会继续迭代 16 次得到 HMAC 校验用的密钥、再 16 次得到口令校验值，共 `2^Lg2 + 32` 次。本工具与 UnRAR / hashcat 的实现完全一致。

**Q：怎么确认程序算得对？**
A：运行 `--selftest`。它使用 hashcat 官方向量：

```
$rar5$16$38466361001011015181344360681307$15$00000000000000000000000000000000$8$cc7a30583e62676a
对应口令：hashcat
```

**Q：中文口令支持吗？**
A：支持。WinRAR 内部按 UTF-8 取密码，本工具同样以 UTF-8 编码候选口令；同时兼容 GBK 编码的字典文件（会自动转换后重试）。

**Q：想重来一遍，进度记录在哪？**
A：删掉同目录下的 `rar5_progress.json` 即可从零开始。

**Q：找到口令后怎么用？**
A：Windows 上用 WinRAR / 7-Zip / Bandizip 打开该压缩包，输入口令即可解压。
